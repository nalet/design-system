# react: getting started

This is the React implementation of the nalet design system. Each component has a page here with a playground to try it in, examples, implementation notes and its props. The principles, the foundations and styles, when to use each component and the patterns are on the guidelines site: **[nalet.github.io/design-system →](https://nalet.github.io/design-system/)**

## in a portal shell

An app that runs inside the portal shell, as a federated module, takes the design system from the shell instead of bundling its own. That way a page never carries two versions of it. How to set this up is on the guidelines site: [apps in a shell →](https://nalet.github.io/design-system/develop/apps-in-a-shell/)
