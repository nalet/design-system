## implementation notes

- Renders a `div` with `role="separator"`. The unlabelled divider also sets `aria-orientation` to match its orientation.
- With a `label`, the rule is two lines with the label between them, all inside the separator. A separator's children are presentational, and no `aria-label` is set from the label: when the words matter, pass the same text as `aria-label`.
- A vertical divider stretches to the height of its flex row with `align-self: stretch`. `label` is ignored on it.
- Pass `aria-hidden="true"` to a divider that only decorates, so it isn't announced.
- Every native `div` attribute passes through, and the `ref` reaches the `div`. What you pass wins over the defaults, including `role`, `aria-orientation` and `aria-label`.

| key | does |
| --- | --- |
| `tab` | Skips it. A divider takes no focus and has no action. |
