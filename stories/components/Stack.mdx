## implementation notes

- It renders a `div` with `display: flex`, or `inline-flex` when you pass `inline`.
- It sets `box-sizing: border-box` and `min-width: 0`, so it can shrink inside other flex and grid layouts.
- `gap` takes 0, 4, 8, 12, 16 (the default), 24, 32, 48 or 64, and resolves to the `--s-*` tokens, so every gap comes from the space scale.
- It is a plain `div` with no role.
- For a real list, render `ul` and `li`, or pass `role="list"` to the stack and `role="listitem"` to each child, so screen readers announce it as a list.
- Today: it is always a `div`. There is no `as` prop.
- Every native `div` attribute passes through, and the `ref` reaches the `div`.
- Your `style` is merged over the base layout, so it can change `display`, the direction and the `gap`.
- `align`, `justify` and `wrap` are applied after your `style`, so they win over it.
