## implementation notes

- Inline code renders a `code` element. A block renders a `pre` with a `code` inside.
- The block keeps spaces and line breaks with `white-space: pre`, and scrolls sideways with `overflow-x: auto` rather than wrapping.
- A `ResizeObserver` on the `pre` and its content tracks whether the block overflows.
- While it overflows, the `pre` is a focusable region, so keyboard users can reach it and scroll it (see the keys below). It shows the `--focus-ring` when focused.
- To give an overflowing block a better name than “code”, pass an `aria-label`, such as “install command”.
- Your `tabIndex`, `role` and `aria-label` go to the `pre` and win over the defaults.
- Native attributes go to its element, the `code` when inline or the `pre` for a block, and so does the `ref`.

| key | does |
| --- | --- |
| `tab` | Skips inline code and a block that fits. |
| `tab`, then arrow keys | While a block's lines run past its edge, it is a focusable region (`tabindex="0"`, `role="region"`, named “code”): `tab` reaches it, and the arrow keys scroll it. A block that fits takes no tab stop. |
