## implementation notes

- It renders a plain `div` with no role and no name.
- Inside it come, in this order: the header row when `header` or `headerAside` is set, the body, and the footer row when `footer` is set.
- In a `flush` card, build the table from the [table](?path=/docs/components-data-display-table--docs) primitives, because today `Table` draws its own 1px frame, which doubles the card's edge.
- Today: the title renders in a `div`. To make it a heading, pass a heading element as `header`. With `margin: 0` and `font: inherit`, it keeps the title's look.
- To make the card a landmark, add `role="region"` and `aria-labelledby` pointing at that heading. `Card` passes both to its container.
- Every native `div` attribute passes to the container, such as `role`, `aria-labelledby` and `id`, and the `ref` reaches it.

| key | does |
| --- | --- |
| `tab` | Skips the card. Focus moves through the controls inside it: the header aside, then the body, then the footer. |
