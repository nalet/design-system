## implementation notes

- the trigger is a ghost `IconButton` with three squares (`icon` replaces them) or, with `buttonLabel`, a default `Button` with your text and a trailing chevron. `size` (`sm` by default, or `md`) and `className` go to the trigger.
- the trigger has `aria-haspopup="menu"`, `aria-expanded`, and `aria-controls` pointing at the menu while it is open.
- the menu exists only while it is open. it renders into `document.body` (a portal), outside any ancestor with `overflow: hidden`: `position: fixed`, `z-index: 150`. it has `role="menu"` and `tabindex="-1"`, and takes its name from the trigger (`aria-labelledby`).
- the items are `<button type="button">` elements with `role="menuitem"` and `tabindex="-1"`: inside the menu, the arrow keys move. a disabled item keeps `aria-disabled="true"`, not the native `disabled`, and stays in the menu. an item's icon sits in a span with `aria-hidden="true"`.
- the menu is measured before it shows (`visibility: hidden` until it is placed), so it never flashes in the wrong place. `align` lines up its `end` edge with the trigger's (the default) or its `start` edge. while it is open it listens for `pointerdown` on the document, to close on a press outside, and for `scroll` (in the capture phase, so any scroll container counts) and `resize` on the window, to follow the trigger.
- on open, focus goes to the first item that isn't disabled, or to the last one after `↑`; when every item is disabled, to the menu itself.
- `onOpenChange(open)` is called when the menu opens and when it closes.
- `loading` puts a spinner in the trigger, sets `aria-busy` and keeps the menu from opening. `disabled` turns the whole menu off. both disable the trigger, so it can't be focused.
- with `buttonLabel`, the visible text is the name, and `label` isn't used. `label` is still required by the type, so pass the same words.
- `ActionMenu` passes no other attributes through.
- axe-core finds no violations, closed or open.

| key | does |
| --- | --- |
| `enter` / `space` on the trigger | opens the menu and focuses its first item that isn't disabled. |
| `↓` on the trigger | the same: opens on the first item. |
| `↑` on the trigger | opens on the last item. |
| `↓` / `↑` in the menu | moves to the next / previous item, wrapping at the ends. disabled items are skipped. |
| `home` / `end` | moves to the first / last item. |
| `enter` / `space` on an item | closes the menu, puts focus back on the trigger, then runs the item. |
| `esc` | closes the menu and puts focus back on the trigger. the key goes no further, so a modal around the menu stays open. |
| `tab` / `shift+tab` | closes the menu, and focus moves on from the trigger as if the menu had not been there. |

## props

<ArgTypes of={ActionMenuStories} />

each entry in `items`:

| field | does |
| --- | --- |
| `id` | a key, unique within the menu |
| `label` | the item's text: a verb and its object |
| `onSelect` | runs once the menu has closed and focus is back on the trigger |
| `disabled` | stays in the menu, can't be run, and the arrow keys skip it |
| `danger` | the label in `--signal-amber`: deletes, or can't be undone |
| `icon` | decoration before the label |
