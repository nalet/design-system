## implementation notes

- There are three cells, `StatusCell`, `DateCell` and `IdentifierCell`, and `relativeDay`, which is the date cell's wording as a function.
- `StatusCell` renders a `span` wrapper with a `Status` and, when there is a `detail`, the detail under it.
- The detail is in the DOM in full, so a screen reader reads all of it. CSS clamps it to two lines on screen.
- A string `detail` is also its `title`, the browser's native tooltip, so the lines that are cut off can still be seen.
- Write the vocabulary once with `defineStates` and spread it in: `<StatusCell {...BACKLOG_STATES[row.state]} detail={why(row)} />`.
- Today: a `detail` that isn't a plain string gets no `title` at all, so its cut-off lines can't be seen on screen.
- `DateCell` renders a `<time>` with the ISO `datetime`, and puts the full weekday, date and time in its `title`.
- The compact relative part is `aria-hidden`, and its words, such as “5 days ago”, are in a visually hidden span, so a screen reader reads the words and not the short form.
- An empty value is an `aria-hidden` dash and a visually hidden “no date”, so a screen reader says “no date” instead of skipping it.
- `value` takes a `Date`, an ISO string or epoch milliseconds. An empty or unreadable value shows the empty text.
- `locale` (default `en-GB`) and `format` (default: day, short month, year) shape the absolute date.
- `relative={false}` drops the relative part, and `emptyText` replaces the dash.
- `now` pins “today” for stories and tests. The cell works out “today” against `now` when it renders, and `now` defaults to the current time.
- `emptyText` changes only the visible dash, and `locale` only the absolute date, so a screen reader still hears “no date”, and the relative words stay in English.
- The date cell builds one formatter per locale and format and reuses it, so a table of thousands of dates stays quick to render.
- `relativeDay(then, now)` is the same wording as a function, for a date mentioned outside a cell, such as “last searched 5 days ago”. It returns both forms, `{ short: '5d ago', long: '5 days ago' }`, and `now` defaults to the current time.
- `IdentifierCell`'s `title` and `text` both take any node, a link included.

| key | does |
| --- | --- |
| `tab` | Passes them by. Nothing in a cell is focusable, unless you put a link in an identifier's `title`. |

## props

### status cell

`StatusCell` takes every [status](?path=/docs/components-feedback-status-status--docs) prop: `state`, `text` (or children), `icon`, `appearance` and `stateLabel`. It also takes the native `<span>` attributes, and all of these go to the status. On top of them, it adds `detail`. `className` goes to the wrapper, and there is no `ref`.

<ArgTypes of={StatusCell} />

### date cell

`DateCell` takes only the props below, and there is no `ref`.

<ArgTypes of={DateCell} />

### identifier cell

`IdentifierCell` takes only the props below, and there is no `ref`.

<ArgTypes of={IdentifierCell} />

### relative days

`relativeDay(then: Date, now?: Date): { short: string; long: string }`. `now` defaults to the current time.
