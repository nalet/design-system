## implementation notes

- It renders a `<div>` holding the label, the control and then the message.
- The control is the one child element.
- The field clones the control with `id` and `aria-describedby`, and with `aria-invalid` and `invalid` when there is an `error`.
- The control's `id` is `htmlFor` when you pass it, otherwise the child's own `id`, otherwise a generated one.
- The field sets that `id` on the child, so `htmlFor` wins over the child's own `id`.
- The label is a native `<label for>` pointing at that `id`, so a click on the label focuses the control.
- Nothing transforms the label: it shows the text you wrote, in the body face, so write it in sentence case.
- The message gets the ID `<control id>-desc`, which is added to any `aria-describedby` the child already has, so a screen reader reads the hint or the error with the control.
- With `error`, the field sets `aria-invalid` and `invalid` on the child. Without it, the field leaves the child's own values alone, and the control keeps whatever its own `invalid` says.
- `required` adds the ` *` marker with `aria-hidden="true"`.
- Today: the field does not pass `required` to the control, so pass `required` (or `aria-required`) to the control yourself.
- The message is not a live region, so an error that appears is not announced.
- The child must be one element that passes `id` and `aria-*` on to its native control, as `Input`, `Select`, `Textarea`, `Checkbox` and `Switch` do.
- A control wrapped in a `<div>` gets nothing: the `id` lands on the div, and the label points at the div.
- Today: `Checkbox` and `Switch` have no `invalid` prop. With `error`, the field still passes `invalid` to them, and React warns about an unknown attribute.
- Other `<div>` attributes, such as `className`, `style` and `data-*`, and the `ref` reach the container.

The field has no keys of its own. The control keeps its native keyboard behaviour, which its own page describes.

| key | does |
| --- | --- |
| `tab` / `shift+tab` | Moves focus to / from the control. The label and the messages are not focusable. |
