## implementation notes

- Renders a `span` unless you choose another element with `as` (`as="p"`, `as="h3"` …); the variant's look stays the same. The element has no margin.
- `Text` adds no role or ARIA. The element you pick with `as` is the semantics: `p` for a paragraph, `h3` for a heading, `span` (the default) for a run inside other text.
- `variant="code"` still renders a `span`, not a `code` element.
- `truncate` makes the element an `inline-block` with `max-width: 100%`, on one line, cut with `text-overflow: ellipsis`, and sets no `title`. Inside a flex row, its container must be allowed to shrink (`min-width: 0`), or it grows to fit the text and nothing is cut.
- Every native attribute passes to the element, and the `ref` reaches it.

| key | does |

| `tab` | Skips it. Text is not in the tab order. |
