## implementation notes

- renders a native `<select>` inside a box (a `<div>`), so the browser and the operating system provide the list and the keyboard model. the chevron is an svg in an `aria-hidden` span over the box's right padding, with `pointer-events: none`.
- give the options as an `options` array (`label`, `value`, optional `disabled`) or as `<option>` children. if you pass both, `options` wins and the children are ignored.
- the component holds no state. use `defaultValue`, or `value` with `onChange`.
- `onChange` can fire on every arrow press while the list is closed: only store the value in it.
- a [field](?path=/docs/components-inputs-field--docs) renders a `<label for>` for it.
- `invalid` sets `aria-invalid="true"` and the `--state-error` border. a field's `error` sets `invalid` for you.
- an empty first option has `value: ''`. pass `required` with it, so the form cannot be sent without a choice.
- `className` lands on the box; every other attribute — `value`, `onChange`, `name`, `required`, `aria-*`, `style` — and the ref land on the native `<select>`. set the width on the container: the box always fills it.
- today: one value only. the box has a fixed height, so `multiple` is not supported.

| key | does |
| --- | --- |
| `tab` / `shift+tab` | moves focus to / from the select. |
| `space` or `alt+↓` | opens the list. which one depends on the platform. |
| `↑` / `↓` | move through the options. on some platforms this changes the value without opening the list. |
| letters | jump to the next option that starts with what you type. |
| `enter` | with the list open, chooses the highlighted option. |
| `esc` | closes the list without choosing. |

## props

the size prop is `selectSize` because `size` is the native attribute (the number of rows shown at once).
