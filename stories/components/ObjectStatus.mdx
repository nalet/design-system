## implementation notes

- renders an inline-flex `<span>` and sets `data-state` on it. it takes no focus, has no keys of its own and doesn't animate.
- the glyph sits in an `aria-hidden` span. `icon={false}` hides it, and `icon` takes your own node in its place, hidden the same way.
- for `warning` and `error`, a visually hidden `warning: ` or `error: ` goes in front of the text. `stateLabel` changes that word: a string replaces it (`stateLabel="fehler"` reads "fehler: failed"), and on a calm state adds one; `false` leaves it out.
- the text is lowercased with `text-transform`; the dom keeps the text you wrote.
- it isn't a live region: a status that changes in place is not announced.
- `text` and `children` fill the same slot (`text` wins when both are given); `text` is what lets a vocabulary entry spread in.
- every other `<span>` attribute (`id`, `title`, `aria-*`, `data-*`) and the `ref` reach the outer `span`.
- axe-core finds no violations, colour contrast included, in any state, as a chip or as text.

### vocabulary: `defineStates`

one table per object: each value, with its state and its words.

```tsx
import { ObjectStatus, defineStates } from '@nalet/design-system';

type LinkValue = 'open' | 'firewalled' | 'checking' | 'down' | 'unknown';

const LINK = defineStates<LinkValue>({
  open: { state: 'success', text: 'open' },
  firewalled: { state: 'warning', text: 'connection firewalled' },
  checking: { state: 'information', text: 'checking' },
  down: { state: 'error', text: 'unreachable' },
  unknown: { state: 'neutral', text: 'not checked yet' },
});

<ObjectStatus {...LINK[row.link]} />
```

`defineStates` returns a frozen copy of the table. pass your value type as the type argument, as above, and typescript makes the table exhaustive: a value without a row, or a row for a value that doesn't exist, is a type error. without the type argument, the keys you write are the type. a reviewer reads in one place that `firewalled` is a warning, not a success.

### sorting: `STATE_SEVERITY`

`STATE_SEVERITY` ranks the states for sorting a list by status, most urgent first: `error` 4, `warning` 3, `information` 2, `neutral` 1, `success` 0.

```tsx
rows.sort((a, b) => STATE_SEVERITY[HOST[b.status].state] - STATE_SEVERITY[HOST[a.status].state]);
```

`OBJECT_STATES` lists the five states from `neutral` to `error`, for a legend or a filter.
