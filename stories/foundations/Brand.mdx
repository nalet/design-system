# brand

two marks carry the identity: the chevron and the lockup. both are inline svg components, drawn in the brand blue, `--cloud-blue`, on the dark canvas.

<Canvas of={BrandStories.Glyphs} />

## the chevron

the `>` is the brand glyph. it reads as a terminal prompt: this is where something starts, and the way in. the library draws it in three places — before the [portal](?path=/docs/patterns-portal--docs) title (18px), before each [tile group](?path=/docs/components-navigation-tile-group--docs) legend (14px), and after the title of a link or button [tile](?path=/docs/components-navigation-tile--docs) on hover and focus (14px) — and it opens the lockup. `Heading`'s `chevron` prop draws the same mark as a text `>` in the heading's font, also in `--cloud-blue`.

- **one colour.** always `--cloud-blue`, on the dark canvas. `Chevron` takes the colour from its own class; its `color` prop can override it, and the brand says don't.
- **sizes.** 16px by default, and any size works. the stroke is 14% of the size, never under 1.5px (`strokeWidth` sets it in px), with rounded ends and corner, so the mark keeps its weight from 14px to 128px.

## the lockup

the chevron, the wordmark in jetbrains mono 700 and a cursor block, in a 300 × 160 box. `height` sets the size (40px by default, which makes it 75px wide); the width follows the ratio. it mirrors the svg file in `assets/terminal/`.

- **with cursor** (the default) — a `--cloud-blue` block after the wordmark blinks: on for half of a 1.05s cycle, off for the other half.
- **without cursor** — `showCursor={false}`: the chevron and the wordmark alone.
- **filled** — `filled` paints a `--bg` rectangle behind the mark, like the svg file. it only shows off the canvas, where it puts the canvas colour behind the mark.

## when to use

- **the lockup** — once on a surface, where people need to know whose it is: the top of a start page, a sign-in screen, a splash.
- **the chevron** — to lead a title or a section, as the portal and the tile groups do; as the prompt at the start of a command-style input; as the way into a destination.

## when not to use

- **the chevron as an arrow in a control** — next, expand, sort, a submenu. use a lucide arrow or chevron through `Icon` (see [iconography](?path=/docs/foundations-iconography--docs)): the brand mark isn't a ui arrow.
- **in another colour, or on a light surface.** the chevron says brand, not state; for a state, use [object status](?path=/docs/components-feedback-status-object-status--docs).
- **more than one cursor on a screen.** the brand has one cursor. show any further lockup with `showCursor={false}`.
- **a blinking cursor that stays in view.** in a header or a sidebar, turn it off with `showCursor={false}` — see accessibility.

## anatomy

the chevron:

1. **mark** — one path, `M5 3 L11 8 L5 13`, in a 16-unit square, drawn in `currentColor`.
2. **stroke** — `strokeWidth` px, or 14% of `size` with a 1.5px floor; rounded caps and join.

the lockup, in its 300 × 160 box:

1. **chevron** — a 9-unit `--cloud-blue` stroke from (46, 50) to (76, 80) to (46, 110), rounded.
2. **wordmark** — 44-unit jetbrains mono 700 in `--fg-2`, starting at x 100 on a baseline at y 100.
3. **cursor** (optional) — a 14 × 48 `--cloud-blue` block at x 240.
4. **fill** (optional) — a `--bg` rectangle behind everything.

## accessibility

- `Chevron` renders `role="img"` with `aria-label="chevron"`. next to a title it is decoration: pass `aria-hidden`, as every use inside the library does. a bare `<Chevron />` is announced as an image called "chevron".
- `Lockup` renders `role="img"`, named by its wordmark. inside a link, it names the link with the wordmark; pass `aria-label` when the link needs other words.
- neither mark takes focus or handles keys.

today:

- the cursor blinks without end. under `prefers-reduced-motion`, the stylesheet hides the cursor's `<animate>` element to hold it still, but css `display` isn't one of the properties that apply to svg animation elements, so a browser can keep it blinking. pass `showCursor={false}` wherever the lockup stays in view: blinking that lasts more than five seconds next to other content needs a way to stop it (wcag 2.2.2).

## brand files

- **`brand/brand.md`** — the brand's rules for people: the canvas, foreground and signal colours, the two type families, the 4-based space scale, square frames and the voice. it names the token file as the source of truth.
- **`brand/llm.txt`** — the same rules, condensed for language-model agents: what the system is, which files to read first, the non-negotiables, and a one-line test of whether a screen is on brand.
- **`tokens/tokens.json`** — the source of truth for every value. when a hex in a brand file disagrees with it, the tokens win: `--fg-dim`, for one, changed this release.
- **`assets/terminal/`** holds the lockup as an svg file; **`assets/icons/`** the app icons as png, 16 to 512px, with their rounded corners baked in.

these pages and the files say the same thing. where they differ, trust the tokens and the components.
