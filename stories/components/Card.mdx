## implementation notes

- Renders a plain `div` with no role and no name. Inside it, in this order: the header row when `header` or `headerAside` is set, the body, and the footer row when `footer` is set.
- In a `flush` card, build the table from the [table](?path=/docs/components-data-display-table--docs) primitives: today `Table` draws its own 1px frame, which doubles the card's edge.
- Today: the title renders in a `div`. To make it a heading, pass a heading element as `header`; with `margin: 0` and `font: inherit` it keeps the title's look. To make the card a landmark, add `role="region"` and `aria-labelledby` pointing at that heading — `Card` passes both to its container.
- Every native `div` attribute passes to the container (`role`, `aria-labelledby`, `id`, …), and the `ref` reaches it.

| key | does |
| --- | --- |
| `tab` | Skips the card; focus moves through the controls inside it — header aside, then body, then footer. |
