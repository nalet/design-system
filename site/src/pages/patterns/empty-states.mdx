# empty states

Sometimes a list has nothing to show. That can be good news, because everything is done. It can be a first visit, before anything was added. Or it can be a problem: the list couldn't load. An <Term id="empty-state">empty state</Term> says which one it is, and what people can do next, so they never have to guess.

## when to show one

Show an empty state in the place of the content: in a table's body, in a [worklist](/design-system/patterns/worklist/) under its filters, or as the whole page, when a list, a table or a page has nothing to show and saying why helps.

Other things look empty for a moment, but need something else:

- **Content that is still loading.** Show the loading state instead; see [loading and progress](/design-system/patterns/loading-and-progress/). An empty state before the content has loaded claims something nobody knows yet.
- **A problem with content that is still on the screen**, such as a refresh that failed. That is a <Term id="message-strip">message strip</Term> above the content; see [message handling](/design-system/patterns/message-handling/).
- **A confirmation**, like “8 episodes queued”. That is a <Term id="toast">toast</Term>.
- **One empty value in a row.** The cell says it: a date cell shows a dash, read out as “no date”.
- **A short table nobody acts on.** Its own one-line empty row is enough.

## anatomy

  <EmptyAnatomy />
  <figcaption>A search that matches nothing, close up.</figcaption>
</figure>

1. **The place.** Where the content would be. The empty state takes the content's place, not the page's: the title, the tabs and the filters stay, so people can change what made the list empty.
2. **The picture.** A simple line drawing for each kind. It is decoration; the words carry the meaning.
3. **The title.** What is true, in a few words. It is a real heading, so people can find it.
4. **The description** (optional). Why, and what to do, in a sentence or two.
5. **The action** (optional). At most one <Term id="emphasized-action">emphasized</Term> button, for the next step, and one quiet one beside it.

## the five kinds

| kind | it says | its action |
| --- | --- | --- |
| Empty | Nothing is here yet | The step that adds the first item |
| Done | Nothing is left to do: good news | Usually none |
| No match | The search or the filters match nothing | “clear filters” |
| Error | The content couldn't be loaded | “try again” |
| Unknown | It can't be told yet | The step that finds out |

## which kind

Pick the kind by what is true, not by what the screen looks like. A list that failed to load, or can't be checked yet, isn't done.

| situation | kind | title | action |
| --- | --- | --- | --- |
| Nothing has been added yet: a new list, a first visit | Empty | “nothing tracked yet” | The step that adds the first item, emphasized: “import a list” |
| Items exist, but none is due yet, like a “not yet aired” tab | Empty | “132 not yet aired” | None |
| The work is done: nothing is left to act on | Done | “nothing missing” | None |
| One tab or filter of the list is done | Done | “nothing needs attention” | None |
| The search or the filters match nothing, but the list has items | No match | “no matches” | “clear filters” |
| The list couldn't load, and there is nothing older to show | Error | “couldn't load the list” | “try again” |
| It can't be told yet: a check hasn't run, or what the library holds is unknown | Unknown | “nothing can be checked yet” | The step that finds out, emphasized: “ask the catalog again” |
| The list is still loading | No empty state | — | The loading state |
| A refresh or an action failed, and the content is still there | No empty state | — | A message strip above it, with a way forward |

## where it goes

- **In a table:** in its body, under the header row, across every column, at the small size.
- **In a worklist:** in place of the table, at the usual size, under the tabs and the filters. Leave the selection toolbar out while the list is empty: there is nothing to select.
- **As the page:** at the large size, when the whole page has nothing to show.
- The title's heading level follows the page around it, so it fits the page's outline.

## what happens next

- **The action works in place.** Pressing “clear filters” clears them, and the list comes back. Pressing “try again” loads the list again, and shows the loading state while it runs. The unknown kind's action starts what finds out, and says so in a toast: “asking the catalog again — the list follows”.
- **The empty state goes as soon as there is something to show.**
- **The filters stay while a search matches nothing**, so people can change one word instead of starting over.
- **An empty state only shows once the content is known.**

## keyboard and screen readers

- The title is a real heading, so people can find the message by its heading. Set its level so that it fits the page.
- The picture is decoration: the title and the description carry the meaning, never the picture or its colour.
- The message isn't read out when it appears. Say the change where people are: the filter bar's count is read out, so “0 of 12” is heard as the search empties the list.
- The action is a button where the message sits, in the usual order of the Tab key.

Today:

- Pressing the action usually removes the message, button and all, so nothing has the <Term id="focus">focus</Term> afterwards. After “clear filters”, move the focus yourself, to the search field for instance.
- The illustrated message doesn't hold you to one emphasized action: it shows whatever buttons it is given.

## the words

- **Title.** What is true, in the list's own words, in a few of them: “nothing missing”, “no matches”, “couldn't load the list”, “nothing can be checked yet”, “nothing tracked yet”. Not “no data”, “empty”, “oops” or “error”.
- **Description.** Why, and what to do, in one or two sentences, in sentence case: “Every aired episode is in the library.”, “Nothing in this list fits the search and filters.”
- **Action.** A verb and what it acts on: “clear filters”, “try again”, “import a list”, “ask the catalog again”.
- **Counts**, when they help: “132 not yet aired”.
- **No technical detail** in the title or the description: no codes, ids or raw errors. When people need them, they go under a message strip's details.
- **Good news is plain.** “nothing needs attention”: no celebration, and no apology.
- **No blame.** “nothing tracked yet”, not “you haven't added anything”.
