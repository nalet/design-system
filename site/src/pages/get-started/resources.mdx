# resources

Where to find everything: the code, the implementation and the brand's files.

## code and implementation

| what | where |
| --- | --- |
| The <Term id="repository">repository</Term> | [github.com/nalet/design-system](https://github.com/nalet/design-system), MIT licensed. Questions and suggestions go there, as issues and pull requests |
| The React subsite | [/design-system/react/](/design-system/react/): every component's playground, examples, notes and settings |
| Releases | [GitHub releases](https://github.com/nalet/design-system/releases): each one carries the packed package, to install from its address |
| The <Term id="changelog">changelog</Term> | [Versioning & changelog](/design-system/get-started/versioning/), from the changelog file in the repository |
| The tokens | [tokens.json](https://github.com/nalet/design-system/blob/main/tokens/tokens.json): the source of every value; see [tokens](/design-system/develop/tokens/) |

## brand files

| file | what it is |
| --- | --- |
| [brand.md](https://github.com/nalet/design-system/blob/main/brand/brand.md) | The brand's rules for people: the canvas, text and signal colours, the two typefaces, the space scale, square frames and the voice |
| [llm.txt](https://github.com/nalet/design-system/blob/main/brand/llm.txt) | The same rules, shortened for AI agents, with a one-line test of whether a screen is on brand |
| [nalet-lockup.svg](/design-system/terminal/nalet-lockup.svg) | The lockup as an image file, on the canvas colour: the chevron, the wordmark and the blinking cursor |
| [App icons](#app-icons) | The app icon, the blue chevron and the n on the canvas, as images from 16 to 512 pixels, with its rounded corners in the image |
| Splash plates: [grid](/design-system/splash-plates/01-grid.png), [mountain](/design-system/splash-plates/02-mountain.png) | Two background images, 1536 × 1024 pixels, for a splash or a sign-in screen |

Where a colour in a brand file and the tokens disagree, the tokens win; see [brand](/design-system/styles/brand/).
