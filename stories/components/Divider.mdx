## implementation notes

- It renders a `div` with `role="separator"`.
- A divider without a label also sets `aria-orientation` to match its orientation.
- With a `label`, the rule is two lines with the label between them, all inside the separator.
- A separator's children are presentational, so most screen readers don't read the label, and no `aria-label` is set from it. When the words matter, pass the same text as `aria-label`.
- A vertical divider stretches to the height of its flex row with `align-self: stretch`.
- `label` is ignored on a vertical divider.
- Pass `aria-hidden="true"` to a divider that only decorates, so it isn't announced.
- Every native `div` attribute passes through, and the `ref` reaches the `div`.
- What you pass wins over the defaults, `role`, `aria-orientation` and `aria-label` included.
