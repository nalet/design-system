## implementation notes

- Renders a native `<button>`, so the browser provides the keyboard model.
- `type` defaults to `"button"`, not the browser's `"submit"`. Pass `type="submit"` for the button that submits a form.
- `loading` shows a spinner in the leading slot, disables the button and sets `aria-busy="true"`; the spinner is a `status` named "loading". The width stays stable.
- `disabled` dims the button to 45% and removes it from the tab order. A disabled or loading button ignores clicks and cannot be focused.
- `leading` and `trailing` take an element, such as `<Icon icon={Rocket} />`; `trailing` is hidden while `loading`.
- The label is lowercased with `text-transform`; the DOM keeps the text you wrote.
- A focused button shows a 2px `--focus-ring` outline on `:focus-visible`.
- Every native `<button>` attribute passes through (`onClick`, `type`, `aria-*` …), and the `ref` reaches the `<button>`.

| key | does |
| --- | --- |
| `tab` / `shift+tab` | Moves focus to / from the button. |
| `enter` / `space` | Activates it. |
