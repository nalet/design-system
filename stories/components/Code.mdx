## implementation notes

- inline renders `code`; a block renders `pre` with a `code` inside.
- the block keeps spaces and line breaks with `white-space: pre`, and scrolls with `overflow-x: auto`.
- a `ResizeObserver` on the `pre` and its content tracks whether the block overflows; while it does, the `pre` is a focusable region (see the keys below) and shows the `--focus-ring` when focused.
- to name an overflowing block better than "code", pass an `aria-label` ("install command"); your `tabIndex`, `role` and `aria-label` go to the `pre` and win over the defaults.
- native attributes go to its element — the `code` when inline, the `pre` for a block — and so does the `ref`.

| key | does |
| --- | --- |
| `tab` | skips inline code and a block that fits. |
| `tab`, then arrow keys | a block whose lines run past its edge is a focusable region (`tabindex="0"`, `role="region"`, named "code") while it overflows: tab reaches it, the arrow keys scroll it. a block that fits takes no tab stop. |
