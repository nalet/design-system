# brand

Two marks carry the identity: the chevron and the lockup. Both are inline SVG components, drawn in the brand blue, `--cloud-blue`, on the dark canvas. The app icon carries them outside the browser.

## the chevron

The `>` is the brand glyph. It reads as a terminal prompt: this is where something starts, and the way in. The library draws it in three places — before the [portal](/design-system/patterns/launchpad-and-tiles/) title (18px), before each <C slug="tile-group" /> legend (14px), and after the title of a link or button <C slug="tile" /> on hover and focus (14px) — and it opens the lockup. `Heading`'s `chevron` prop draws the same mark as a text `>` in the heading's font, also in `--cloud-blue`.

- **One colour.** Always `--cloud-blue`, on the dark canvas. `Chevron` takes the colour from its own class; its `color` prop can override it, and the brand says don't.
- **Sizes.** 16px by default, and any size works. The stroke is 14% of the size, never under 1.5px (`strokeWidth` sets it in px), with rounded ends and corner, so the mark keeps its weight from 14px to 128px.

## the lockup

The chevron, the wordmark in JetBrains Mono 700 and a cursor block, in a 300 × 160 box. `height` sets the size (40px by default, which makes it 75px wide); the width follows the ratio. It mirrors the SVG file in `assets/terminal/`.

- **With cursor** (the default) — a `--cloud-blue` block after the wordmark blinks: on for half of a 1.05s cycle, off for the other half.
- **Without cursor** — `showCursor={false}`: the chevron and the wordmark alone.
- **Filled** — `filled` paints a `--bg` rectangle behind the mark, like the SVG file. It only shows off the canvas, where it puts the canvas colour behind the mark.

## when to use

- **The lockup** — once on a surface, where people need to know whose it is: the top of a start page, a sign-in screen, a splash, the [shell bar](/design-system/patterns/shell-bar/).
- **The chevron** — to lead a title or a section, as the portal and the tile groups do; as the prompt at the start of a command-style input; as the way into a destination.

## when not to use

- **The chevron as an arrow in a control** — next, expand, sort, a submenu. Use a Lucide arrow or chevron through `Icon` (see [iconography](/design-system/styles/iconography/)): the brand mark isn't a UI arrow.
- **In another colour, or on a light surface.** The chevron says brand, not state; for a state, use <C slug="object-status" />.
- **More than one cursor on a screen.** The brand has one cursor. Show any further lockup with `showCursor={false}`.
- **A blinking cursor that stays in view.** In a header or a sidebar, turn it off with `showCursor={false}` — see [accessibility](#accessibility).

## anatomy

The chevron:

1. **Mark** — one path, `M5 3 L11 8 L5 13`, in a 16-unit square, drawn in `currentColor`.
2. **Stroke** — `strokeWidth` px, or 14% of `size` with a 1.5px floor; rounded caps and join.

The lockup, in its 300 × 160 box:

1. **Chevron** — a 9-unit `--cloud-blue` stroke from (46, 50) to (76, 80) to (46, 110), rounded.
2. **Wordmark** — 44-unit JetBrains Mono 700 in `--fg-2`, starting at x 100 on a baseline at y 100.
3. **Cursor** (optional) — a 14 × 48 `--cloud-blue` block at x 240.
4. **Fill** (optional) — a `--bg` rectangle behind everything.

## the app icon

The chevron and the n, on the canvas, in a square with rounded corners — with the line icons, the only rounded shape in the system. It comes as PNG files from 16 to 512px, with the corners baked in; never round anything else to match it. The files are on [resources](/design-system/get-started/resources/#app-icons).

## accessibility

- `Chevron` is an image named "chevron". Next to a title it is decoration: hide it from assistive tech (`aria-hidden`), as every use inside the library does.
- `Lockup` is an image named by its wordmark. Inside a link, it names the link with the wordmark; give the link its own name when it needs other words.
- Neither mark takes focus or handles keys.

Today:

- The cursor blinks without end. Under `prefers-reduced-motion`, the stylesheet hides the cursor's `<animate>` element to hold it still, but CSS `display` isn't one of the properties that apply to SVG animation elements, so a browser can keep it blinking. Pass `showCursor={false}` wherever the lockup stays in view: blinking that lasts more than five seconds next to other content needs a way to stop it (WCAG 2.2.2). On this site, the examples with a cursor have a pause control.

## brand files

- **`brand/brand.md`** — the brand's rules for people: the canvas, foreground and signal colours, the two type families, the 4-based space scale, square frames and the voice. It names the token file as the source of truth.
- **`brand/llm.txt`** — the same rules, condensed for language-model agents: what the system is, which files to read first, the non-negotiables, and a one-line test of whether a screen is on brand.
- **`tokens/tokens.json`** — the source of truth for every value. When a hex in a brand file disagrees with it, the tokens win: `--fg-dim`, for one, changed in 0.3.0.
- **`assets/terminal/`** holds the lockup as an SVG file; **`assets/icons/`** the app icon as PNG, 16 to 512px.

These pages and the files say the same thing. Where they differ, trust the tokens and the components. Links to every file are on [resources](/design-system/get-started/resources/).
