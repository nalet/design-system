# resources

Where everything lives: the code, the implementation, the brand files.

## code and implementation

| what | where |
| --- | --- |
| The repository | [github.com/nalet/design-system](https://github.com/nalet/design-system) — MIT licensed; issues and pull requests go there |
| The React subsite | [/design-system/react/](/design-system/react/) — every component's playground, examples, implementation notes and props |
| Releases | [GitHub releases](https://github.com/nalet/design-system/releases) — each carries the packed package to install by URL |
| The changelog | [Versioning & changelog](/design-system/get-started/versioning/), from `CHANGELOG.md` |
| The tokens | [`tokens/tokens.json`](https://github.com/nalet/design-system/blob/main/tokens/tokens.json) — the source of every value; see [tokens](/design-system/develop/tokens/) |

## brand files

| file | what it is |
| --- | --- |
| [`brand/brand.md`](https://github.com/nalet/design-system/blob/main/brand/brand.md) | The brand's rules for people: canvas, foreground and signal colours, the two type families, the space scale, square frames and the voice |
| [`brand/llm.txt`](https://github.com/nalet/design-system/blob/main/brand/llm.txt) | The same rules, condensed for language-model agents, with a one-line test of whether a screen is on brand |
| [`nalet-lockup.svg`](/design-system/terminal/nalet-lockup.svg) | The lockup as an SVG file, on the canvas colour: chevron, wordmark and the blinking cursor |
| [App icons](#app-icons) | The app icon — the blue chevron and the n on the canvas — as PNG, 16 to 512px, with its rounded corners baked in |
| Splash plates: [grid](/design-system/splash-plates/01-grid.png), [mountain](/design-system/splash-plates/02-mountain.png) | Two 1536 × 1024 backgrounds for a splash or a sign-in screen |

Where a hex value in a brand file and `tokens/tokens.json` disagree, the tokens win; see [brand](/design-system/styles/brand/).
