## implementation notes

- Renders a plain `span` with no role, so screen readers read it inline. It takes no focus and has no keys of its own.
- The dot is a `span` with `aria-hidden="true"`.
- The label is lowercased with `text-transform`; the DOM keeps the text you wrote.
- It never wraps (`white-space: nowrap`) and has no `max-width`.
- Don't attach `onClick`: the `span` can't be focused or pressed from the keyboard. An action is a [button](?path=/docs/components-actions-button--docs).
- Every native `<span>` attribute passes through (`id`, `title`, `aria-*` …), and the `ref` reaches the `span`.

| key | does |
| --- | --- |
| `tab` | Skips it. A badge is not focusable and has no action. |
