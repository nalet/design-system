## implementation notes

- It renders a plain `span` with no role, so a screen reader reads it inline, as part of the text around it.
- It takes no focus and has no keys of its own.
- The dot is a `span` with `aria-hidden="true"`, so only the label is read.
- The label is lowercased with `text-transform`, but the DOM keeps the text you wrote, so write it the way it should be read.
- It never wraps (`white-space: nowrap`) and has no `max-width`.
- Don't attach `onClick`: a `span` can't be focused or pressed from the keyboard, so keyboard users could never reach the action. An action is a [button](?path=/docs/components-actions-button--docs).
- Every native `<span>` attribute passes through, such as `id`, `title` and `aria-*`, and the `ref` reaches the `span`.

| key | does |
| --- | --- |
| `tab` | Skips it. A badge is not focusable and has no action. |
