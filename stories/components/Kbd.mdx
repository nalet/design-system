## implementation notes

- It renders a native `<kbd>` and nothing else: no key listener and no focus.
- It is `inline-flex` and `white-space: nowrap`, so a key's label stays on one line.
- It has no `text-transform`, so the label shows exactly as you wrote it.
- Every native `<kbd>` attribute passes through, and the `ref` reaches the `<kbd>`.
- Its children are the key's label.

| key | does |
| --- | --- |
| `tab` | Skips it. A keycap takes no focus. |
