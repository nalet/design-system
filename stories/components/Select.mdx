## implementation notes

- It renders a native `<select>` inside a box (a `<div>`), so the browser and the operating system provide the list and the keyboard behaviour.
- The chevron is an SVG in an `aria-hidden` span over the box's right padding, with `pointer-events: none`. Today: the padding is outside the native `<select>`, so a click on the chevron lands on the box and doesn't open the list.
- You can give the options as an `options` array (`label`, `value` and an optional `disabled`) or as `<option>` children. If you pass both, `options` wins and the children are ignored.
- The component holds no state of its own. Use `defaultValue`, or `value` with `onChange`.
- `onChange` can fire on every arrow press while the list is closed, so only store the value in it.
- A [field](?path=/docs/components-inputs-field--docs) renders a `<label for>` for it, so the select is named by the field's label.
- `invalid` sets `aria-invalid="true"` and the `--state-error` border. A field's `error` sets `invalid` for you.
- An empty first option has `value: ''`. Pass `required` with it, so the form can't be sent until someone makes a choice.
- `className` lands on the box. Every other attribute (`value`, `onChange`, `name`, `required`, `aria-*`, `style`) and the ref land on the native `<select>`.
- The box always fills its container, so set the width on the container.
- Today: a select holds one value only. The box has a fixed height, so `multiple` is not supported.

| key | does |
| --- | --- |
| `tab` / `shift+tab` | Moves focus to / from the select. |
| `space` or `alt+↓` | Opens the list. Which of the two works depends on the platform. |
| `↑` / `↓` | Move through the options. On some platforms this changes the value without opening the list. |
| Letters | Jump to the next option that starts with what you type. |
| `enter` | With the list open, chooses the highlighted option. |
| `esc` | Closes the list without choosing. |

## props

The size prop is called `selectSize` because `size` is already a native attribute of `<select>`: the number of rows shown at once.
