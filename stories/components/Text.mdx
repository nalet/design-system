## implementation notes

- It renders a `span` unless you choose another element with `as` (`as="p"`, `as="h3"` …). The variant's look stays the same whichever element you choose.
- The element has no margin, so a `p` or an `h3` doesn't bring the browser's default spacing with it.
- `Text` adds no role or ARIA. The element you pick with `as` carries the meaning: `p` for a paragraph, `h3` for a heading, `span` (the default) for a run inside other text.
- `variant="code"` still renders a `span`, not a `code` element.
- `truncate` makes the element an `inline-block` with `max-width: 100%`, keeps it on one line and cuts it with `text-overflow: ellipsis`.
- `truncate` sets no `title`, so the full text doesn't appear on hover.
- Inside a flex row, its container must be allowed to shrink (`min-width: 0`). Otherwise the container grows to fit the text, and nothing is cut.
- Every native attribute passes to the element, and the `ref` reaches it.

| `tab` | Skips it. Text is not in the tab order. |
