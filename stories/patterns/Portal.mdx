## implementation notes

- `Portal` renders an optional title bar — the title as an `<h1>` with an 18px chevron, and the search, a `role="search"` landmark around a text input named by `searchLabel` ("search apps" by default) — then `favorites`, then its children, the `TileGroup`s, then the empty state and a visually hidden polite live region with the match count.
- The search is uncontrolled by default. Pass `query` with `onQueryChange` to control it; `onQueryChange` fires on every keystroke either way. A controlled `query` without `onQueryChange` freezes the search box.
- Matching is on each tile's `data-nc-search` (its title and description, lowercased), which `Tile` sets. Tiles that don't match are hidden, and so is a group left without a match (the `hidden` attribute); a hidden tile never keeps the tab stop.
- `/` with focus in the body moves focus to the search; `esc` in the search clears it and moves focus to the first tile.
- `navigation="roving"` (the default) runs one roving-grid model across every tile in the body, favourites included. It is `useRovingGrid(ref, enabled)`, which the library exports: it keeps one `[data-nc-tile]` element under `ref` at `tabindex="0"` and the rest at `-1`, and returns the `onKeyDown` handler for the container — a custom launcher can reuse it. `navigation="tab"` turns it off; each tile group then runs its own model unless it is given `navigation="tab"` too.
- `density="compact"` tightens the spaces: 16px under the title bar instead of 24, 24px between groups instead of 32.
- `Portal` passes other attributes and its `ref` to its root `<div>`.
