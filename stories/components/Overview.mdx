# components

every component of `@nalet/design-system`, grouped by what it is for. each page has the same anatomy: when to use it and when not (with the alternative), anatomy, variants and states, behaviour and keyboard, accessibility, content, do and don't, props, and related pages.

## actions

| component | for |
| --- | --- |
| [button](?path=/docs/components-actions-button--docs) | an action on this screen; `primary` is the one emphasized action |
| [icon button](?path=/docs/components-actions-icon-button--docs) | the same action with an icon only, and a required name |
| [action menu](?path=/docs/components-actions-action-menu--docs) | several actions behind one trigger — e.g. one menu per table row |
| [toolbar and selection toolbar](?path=/docs/components-actions-toolbar--docs) | actions above the content they act on; the selection toolbar's one emphasized action follows the selection |

## inputs

| component | for |
| --- | --- |
| [input](?path=/docs/components-inputs-input--docs) | one line of text |
| [textarea](?path=/docs/components-inputs-textarea--docs) | several lines of text |
| [select](?path=/docs/components-inputs-select--docs) | one value from a list (native) |
| [multi select](?path=/docs/components-inputs-multi-select--docs) | several values of a facet, as checkboxes in a disclosure |
| [checkbox](?path=/docs/components-inputs-checkbox--docs) | an option that is saved with a form; indeterminate for a partial group |
| [switch](?path=/docs/components-inputs-switch--docs) | a setting that takes effect at once |
| [field](?path=/docs/components-inputs-field--docs) | a label, hint and error wired to one control |
| [filter bar](?path=/docs/components-inputs-filter-bar--docs) | search, facets, clear all and the count of what is left |
