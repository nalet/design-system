## implementation notes

- Fully controlled: the bar holds no values of its own. Each value comes from you and goes back through its `onChange`; the list filters itself from them.
- Renders a `<div role="search">` named by `label` (`aria-label`, default "filters").
- `search` renders an `Input` with `type="search"`, named by `search.label` (`aria-label`, default "search").
- Each `select` facet is a native `Select` inside its own `<label>`; a `multiselect` facet is a `MultiSelect`.
- `collapseBelow` (640 by default) is compared with the bar's own width, measured with a `ResizeObserver`. Until the bar has been measured, and wherever there is no `ResizeObserver`, it lays out wide.
- Narrow, the toggle has `aria-expanded`, and `aria-controls` pointing at the facets. Folded facets are `hidden`.
- The count is a live region, `aria-live="polite"` with `aria-atomic="true"`. It is always on the page, empty while there is no `resultCount`, so the first count is announced too.
- `clear all` calls `onClearAll`. Reset the search and every facet there.
- axe-core finds no violations, with a multi select open.
- Other `<div>` attributes and the `ref` reach the `role="search"` element.

| key | does |
| --- | --- |
| `tab` / `shift+tab` | Native order: the search, each facet, your controls, `clear all`. Narrow: the search, the `filters` toggle and, while it is open, the facets, your controls and `clear all`. A disabled `clear all` is skipped. |
| Typing in the search | Calls `search.onChange` on every keystroke: the list filters as the person types. |
| `esc` in the search | Clears it, when it holds text. A modal around the bar stays open. On an empty search, the key goes on to the page. |
| Keys in a select facet | Native: see [select](?path=/docs/components-inputs-select--docs). |
| Keys in a multi select facet | See [multi select](?path=/docs/components-inputs-multi-select--docs). |
| `enter` / `space` on the `filters` toggle | Shows or hides the facets. |

## props

<ArgTypes of={FilterBarStories} />

`search` takes `value`, `onChange`, `placeholder` and `label` (default "search"). Each entry in `filters` is one facet:

| field | `select` facet | `multiselect` facet |
| --- | --- | --- |
| `type` | `"select"` | `"multiselect"` |
| `id` | A key, unique in the bar | The same |
| `label` | The facet's name, shown before the select | The multi select's label |
| `value` | A string | An array of strings |
| `onChange` | Gets the new string | Gets the new array |
| `options` | `value` and `label`, the no-filter option first | `value`, `label` and an optional `count` |
| `emptyValue` | The value that means no filter, default `""` | — |
