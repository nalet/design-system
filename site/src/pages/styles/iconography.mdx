# iconography

line icons from [lucide](https://lucide.dev), drawn through `Icon`: 16px, a 1.75 stroke, the colour of the text around them, and hidden from assistive tech unless you name them.

<Example label="a few icons at the default size">
  <Gallery />
</Example>

## the icon component

- `Icon` takes the lucide component in `icon` — the component, not an element: `<Icon icon={Terminal} />`.
- `size` is the edge length in px: 16 by default, to match the ui text. `strokeWidth` is 1.75 by default; lucide's own default is 2.
- the stroke is `currentColor`, so an icon takes the colour of its parent. tint the parent, not the icon.
- it is hidden from assistive tech unless you pass an `aria-label`.

how it is built — the element it renders, the props it passes through — is on its [react page](/design-system/react/?path=/docs/components-brand-icons-icon--docs).

## lucide is a peer dependency

- install `lucide-react` (0.300.0 or later) next to the library; `react` and `react-dom` 18 or later are peers too.
- the library imports lucide for its types only and bundles no icons. import each icon you use by name — `import { Terminal } from 'lucide-react'` — and your bundle carries only those.
- where a component takes an icon, it wants the component: `Icon`'s `icon`, `Tile`'s `icon`. slots take an element: a <C slug="button" />'s `leading={<Icon icon={Rocket} />}`, or the icon as an <C slug="icon-button" />'s child.

## sizes

| size | where |
| --- | --- |
| 12px | inside `sm` (28px) buttons and icon buttons, the size of their spinner |
| 16px | the default: next to ui text, inside `md` (34px) buttons and icon buttons |
| 20px | inside `lg` (42px) icon buttons |
| 22px | a tile's app icon. `Tile` sets the size and the stroke; you pass only the component |

<Example label="icon sizes">

</Example>

the stroke stays 1.75 at every size. lucide measures it on its 24-unit grid, so the line thins as the icon shrinks: about 1.2px at 16px, 1.6px at 22px. don't mix stroke widths on one screen.

## colour

- icons are `currentColor`: next to body text they are `--fg-2`, in a quiet label `--fg-muted`.
- `--cloud-blue` marks a destination: it is the colour of a tile's app icon.
- the signal colours belong to states, and a state needs words: see <C slug="object-status" />. an icon alone in green or red tells many people nothing.

## decoration and meaning

- **next to words, an icon is decoration.** `Icon` hides it from assistive tech, and the words carry the meaning — in a button's slots, in a tile.
- **an icon that is a control's only content** belongs in an <C slug="icon-button" />. its required `label` becomes the button's accessible name and its native tooltip; leave the icon inside unlabelled.
- **an icon that informs on its own** is rare. give it a name — `aria-label` with `role="img"` — and `Icon` stops hiding it. words next to it are still better.
- **never make a bare icon clickable.** an `<svg>` takes no focus and has no role, so keyboard and screen-reader users can't use it.

## shape

icons are the only rounded shape in the system: lucide draws them with round caps and joins, and the app icons carry their rounded corners in the png. everything around an icon stays square — see [shape](/design-system/styles/shape/).
