## implementation notes

- It renders an `<a>` with `href`, a `<button type="button">` with `onClick`, your own element with `as`, and otherwise a `<div>`.
- A `disabled` tile is always a `<div>`, so it has no link, no click and no focus.
- Link, button and `as` tiles are interactive, so they get the hover, the focus frame and the chevron.
- A display-only `<div>` gets none of them and can't take focus.
- `as` renders your own component, for example a router link.
- Today: `Tile` passes `href` and `external` only to a plain `<a>`, so give your component its destination yourself.
- With an `href`, `external` sets `target="_blank"` and `rel="noopener noreferrer"`.
- Today: nothing on the tile says that it opens a new tab.
- Interactive tiles set the `data-nc-tile` attribute. In a [tile group](?path=/docs/components-navigation-tile-group--docs) or a [portal](?path=/docs/patterns-portal--docs), the arrow keys move between the elements that carry it.
- Every tile carries its title and description, lowercased, in `data-nc-search`, and the [portal](?path=/docs/patterns-portal--docs) search matches against it.
- `icon` takes the Lucide component, not an element, because the tile draws it itself, at 22px with a 1.75 stroke.
- The icon, the chevron and the delta's triangle are `aria-hidden`.
- The status dot has `role="img"` and the label `status: <status>`, so screen readers say the status in words.
- `selected` is visual only. Pass `aria-current="page"` on the current app's tile yourself. It reaches the element, as other attributes do.
- Today: a disabled tile is a `<div>` with `aria-disabled`, which assistive tech ignores on a plain element.
- Today: focus shows on `:focus-visible` as a 2px `--cloud-blue` frame, not the `--focus-ring` outline that other controls use.
- Transitions are off under `prefers-reduced-motion`.
- A tile fills its grid cell, so on its own it needs a width, like the playground's 280px.
- Every other attribute and the `ref` reach the element it renders (`aria-current`, `target`, `data-*`, …).

A link or button tile is a native `<a>` or `<button>`, so the browser gives it the keys for free.

| key | does |
| --- | --- |
| `tab` / `shift+tab` | Moves focus to / from the tile. In a tile group, the group decides which tile is in the tab order: see [tile group](?path=/docs/components-navigation-tile-group--docs). |
| `enter` | Link: follows it. Button: presses it. |
| `space` | Button: presses it. |
